### Auditor: 

The audit tool checks and verifies timestamps for claimed predictions. It is available in a choice of python or powershell script. The prediction proofs generated by the auditor consist of these events in linear time:

1. Model output files are committed here with CVE ratings of their likelihood of being watch-listed.
2. These model ratings are checked against KEVs (known exploited vulnerabilities) lists.
3. When a prediction rating here was timestamped prior to the date of a KEV entry, that counts as a true prediction, for a CVE, because the prediction preceded the KEV listing.

audit.py - the python version of the audit script

audit.ps1 - the powershell version of the audit script

The CSV and TXT files are saved outputs from the two scripts. 

[Errata](errata.md) - contains a log of predictions disqualified by the auditor.
